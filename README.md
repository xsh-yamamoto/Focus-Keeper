# Focus Keeper - 開発ドキュメント

## 1. プロジェクト概要

**名称:** Focus Keeper (フォーカス・キーパー)
**バージョン:** 1.0
**プラットフォーム:** Google Chrome 拡張機能 (Manifest V3)
**目的:**
業務中の過集中（オーバーワーク）を防ぐためのポモドーロ・テクニック風タイマー機能と、業務工数管理（作業時間の記録）を統合したツール。

## 2. 機能仕様

### 2.1 タイマー機能

* **作業タイマー:** 任意の時間（分単位）を設定可能。デフォルト25分。
* **休憩タイマー:** 任意の時間（分単位）を設定可能。デフォルト5分。
* **バックグラウンド動作:** ポップアップを閉じてもカウントダウンは継続する。
* **通知:** 設定時間が経過した際、デスクトップ通知（OSネイティブ通知）を表示する。

### 2.2 工数管理・履歴機能

* **作業内容選択:** 作業開始時に「案件」「自社作業」「個人作業」などのカテゴリを選択可能。
* **自動記録:** タイマーが完走（通知発火）した時点で、日時・カテゴリ・所要時間を自動保存。
* **履歴表示:** ポップアップ画面内で直近の履歴リストを閲覧可能。
* **CSV出力:** 蓄積された履歴データをCSVファイルとしてダウンロード可能（Excel/Spreadsheet対応）。

## 3. ファイル構成

プロジェクトフォルダ（例: `focus-timer`）内に以下のファイルを配置する。

```text
focus-timer/
├── manifest.json   (設定ファイル)
├── popup.html      (画面レイアウト)
├── popup.js        (画面ロジック)
├── background.js   (バックグラウンド処理)
└── icon.png        (任意: アイコン画像)

```

## 6. インストール手順

1. PC上の任意の場所にフォルダ（例: `focus-timer`）を作成し、上記の4ファイルを保存する。
2. Google Chromeを開き、アドレスバーに `chrome://extensions` と入力する。
3. 右上の **「デベロッパーモード」** をONにする。
4. **「パッケージ化されていない拡張機能を読み込む」** をクリックする。
5. 作成したフォルダを選択する。
6. 拡張機能一覧に「Focus Keeper」が表示されればインストール完了。

## 7. ユーザーマニュアル (操作方法)

### STEP 1: 設定と開始

1. ブラウザ右上の拡張機能アイコンをクリックして画面を開きます。
2. **作業時間（分）** と **休憩時間（分）** を入力します（初期値: 25分/5分）。
3. **作業内容** プルダウンから、これから行う作業の種類（案件・自社作業など）を選択します。
4. **「作業スタート」** ボタンを押します。

### STEP 2: 作業中

* タイマーがカウントダウンを開始します。
* 画面を閉じてもタイマーは止まりません。
* 途中でやめる場合は、画面を開いて「リセット」を押してください（この場合、履歴には残りません）。

### STEP 3: 完了と休憩

* 時間が来るとデスクトップ通知が表示されます。
* この時点で作業履歴が自動保存されます。
* 画面を開くとボタンが **「休憩スタート」** に変わっています。クリックして休憩を開始してください。

### STEP 4: 履歴の活用

* 画面下部の「作業履歴」エリアで直近の活動を確認できます。
* **「CSV出力」** ボタンを押すと、全履歴を `focus_history.csv` としてダウンロードできます。
* **「履歴クリア」** を押すと、保存されている履歴が全て削除されます。
